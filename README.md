# Quick Answer Overlay (Chrome Extension + Spring Boot)

This project captures a screenshot only when you trigger the shortcut, sends it through the Spring Boot backend to CodeCraft API using a vision-capable model, and displays the concise response in a small movable overlay on the current webpage for five seconds. It does not open a side panel or a new tab during use.

Use this for practice questions and assessments where AI assistance is permitted.

## Project layout

- `chrome-extension/` — unpacked Chrome extension (Manifest V3)
- `spring-backend/` — Spring Boot REST API that keeps the AI API key out of extension files

## Requirements

- Google Chrome
- Java 21+
- Maven 3.9+ (or use the Maven wrapper generated by your IDE)
- A CodeCraft API key and access to a vision-capable model

## 1. Configure the AI API key

Set `CODECRAFT_API_KEY` in your environment. Do not put the key in `background.js`, `options.js`, `manifest.json`, or any file packaged with the extension.

Windows PowerShell (current terminal only):

```powershell
$env:CODECRAFT_API_KEY="cc_your_actual_key_here"
$env:CODECRAFT_MODEL="claude-opus-4.8"
cd spring-backend
mvn spring-boot:run
```

The configured default endpoint is `https://codecraftapi.com/v1/chat/completions`. The default model is `claude-opus-4.8`; confirm it is listed for your account and advertises the `vision` capability. You can override it with `CODECRAFT_MODEL` and the base URL with `CODECRAFT_BASE_URL` (normally leave the base URL unchanged). See the [CodeCraft Vision docs](https://codecraftapi.com/docs/vision) and [Models docs](https://codecraftapi.com/docs/models).

## 2. Load the extension

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this project's `chrome-extension` folder.
5. Open **Details → Extension options** only if you need to change the backend URL. The options page is not opened during normal use.

## 3. Use it

1. Keep the Spring Boot backend running on `http://localhost:8080`. The API key stays in the backend environment and is not stored in the extension.
2. Open a webpage with a practice multiple-choice question.
3. Press **Ctrl+Shift+Y**. If Chrome reports a shortcut conflict, open `chrome://extensions/shortcuts` and assign another available shortcut.
4. The extension captures the visible tab, sends the screenshot to your local backend, and displays the AI response in a movable overlay.
5. The overlay disappears after five seconds. Drag it to reposition it or click × to close it sooner.

## Notes and limitations

- This is on-demand screenshot capture, not continuous recording. The image is sent to the configured AI API through your local backend for processing.
- The overlay is injected into the webpage, so it does not open a separate Chrome window or side panel. It may not work on restricted browser pages such as `chrome://` pages, the Chrome Web Store, or other pages where Chrome blocks extensions.
- Browser permission prompts, browser UI, and protected video content are not guaranteed to be capturable.
- The AI may misread questions, option labels, or question numbers. Verify answers when accuracy matters.
- API use may incur charges and screenshots may contain private information. Only use it on content you are permitted to process.
- This starter project does not click or select answers on the test page.
